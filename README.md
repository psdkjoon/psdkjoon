`psdk` is me. `joon` is my machine — the Arch box everything gets built and run on. Squash them
together mid-commit and that's the name I code under. (`joon` is also Persian for "dear," so it
kind of just means "dear psdk." Wasn't planned, just worked out that way.)

I'm Gilak, from the wet, green north of Iran. I've been writing code for six years, mostly in
pure Dart — desktop apps, Android apps, backend services, APIs, and the occasional package released
into the wild. Flutter shows up when a project needs a UI. Python, JavaScript, and Bash show up when
a project needs whatever they're good at.

> I don't code for money. I code because I genuinely enjoy it.
